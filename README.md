# Дорога домой 🐾

Тёплая семейная браузерная игра о том, как провести пушистую команду через шесть коротких воздушных маршрутов. Статический сайт: HTML, CSS, JavaScript ES-модули и Canvas — без сборки, серверной части, аналитики, шрифтов/CDN и сторонних runtime-зависимостей.

## Играйте

**GitHub Pages:** <https://miagpt.github.io/game/> (адрес публикуемого сайта; доступность подтвердить по успешному deployment).<br>
**Локально:** Node.js 18+; `npm start`, затем открыть <http://localhost:8000>.

Нажмите **Начать приключение**, выберите пилота, нажимайте пробел/↑/W или касайтесь игрового поля, чтобы взлетать. Esc/кнопка Ⅱ — пауза. Звук синтезируется браузером и выключается кнопкой ♫. Шесть глав, пять базовых и шесть открываемых миссиями бонусных карточек, жизни, лапки, звёзды, три усиления, три косметических наряда, миссии, заметки и финальное письмо. Прогресс хранится локально; после первой победы открывается бесконечный режим. Нет аккаунтов, сетевых запросов или таблицы лидеров.

## Структура

- `index.html` — адаптивная главная, маршрут, выбор пилота, Canvas-игра и фотохроника.
- `assets/js/main.js` — игровой цикл, UI и ввод.
- `assets/js/rules.js` — единый источник баланса уровней, карточек, звёзд и безопасной нормализации сохранения.
- `assets/js/config.js` — заметки, письмо, опциональная дата праздника, миссии и каталог нарядов.
- `assets/css/responsive.css` — мобильная компоновка журнала, миссий и гардероба.
- `assets/img/family/` — оптимизированные WebP-фотографии из вложений.
- `tools/` — тесты, минимальный dev-сервер и сборка allowlist-артефакта GitHub Pages.
- `.github/workflows/pages.yml` — тестирует проект и публикует только allowlist из `dist/`.
- `MASTER-CONTEXT-PROMPT2.MD` — исправленная спецификация, аудит и план дальнейшего развития.

## Проверки и сборка

```sh
npm test                   # unit + локальные ресурсы + 3 000 seed-проверок уровня/пилота
npm start                  # статический сервер для ручной проверки
npm install --no-save puppeteer-core@24.31.0
CHROME_PATH=/path/to/chrome npm run test:e2e  # браузерный E2E
node tools/build-site.mjs  # Pages-каталог dist из allowlist
```

Перед публикацией проверьте страницу на реальном телефоне: размер Canvas, touch, звук после жеста, поворот экрана и пауза при уходе вкладки в фон. Тесты не заменяют ручную проверку баланса.

## Безопасность и приватность

Игра хранит только игровой прогресс в `localStorage` (`doroga-domoy.save.v2`) на текущем устройстве. Битое/недоступное хранилище не блокирует старт.

У репозитория публичная видимость. Корневые ZIP-вложения, включая исходные изображения, и видео не входят в опубликованный Pages-артефакт: workflow собирает страницу из allowlist. Но файлы, уже закоммиченные в Git, остаются доступны через GitHub и его историю. Удаление из будущего коммита не очищает историю; если какие-то вложения не предназначались для публичного доступа, отдельно согласуйте безопасную очистку истории/видимость репозитория до публичного распространения. Производные оптимизированные семейные фото в самой игре публичны по замыслу владельца.

## Публикация

Workflow `Publish family game to GitHub Pages` запускается при push в `main` и рабочую ветку разработки. До первого успешного запуска нужно включить GitHub Pages: **Settings → Pages → Build and deployment → Source: GitHub Actions**. Файл workflow намеренно не делает полную копию корня репозитория: архивация вложений/видео исключена.
