# Happy Home

Семейная браузерная игра на Canvas: пять героев, пять глав и пятьдесят раундов. Без установки, аккаунтов и рекламы. Главная страница репозитория уже открывает Happy Home; прежние страницы игры «Поршик 2.0» пока сохранены отдельно (`play.html`, `love.html`, `covers.html`) как временные legacy-разделы.

**Локально:** `npm start`, затем <http://localhost:8000>.
**Прототипная вложенная страница:** <http://localhost:8000/happy-home/>.
**Текущее состояние GitHub Pages:** код готовится в ветке разработки; опубликованный URL ещё не переключён на Happy Home.

## Игровая версия

- Пять героев по возрасту: Поршик (5), Арчи (6), Грэйс (8), Егор (10), Лиза (16).
- Пять тематических глав, по десять раундов на главу. Последний раунд каждой главы — босс.
- У каждого раунда есть отдельные название, задание и код паттерна. Текст задания показывается прямо под игровой сценой и объявляется assistive technology; новые приёмы постепенно вводятся и сочетаются.
- Сенсорное управление одним касанием, клавиатура на компьютере, пауза, мягкое восстановление и локальные чекпоинты.
- Отдельные переключатели музыки и звуковых эффектов. Web Audio запускается после жеста пользователя.
- Прогресс сохраняется только в `localStorage` этого браузера. Нет аккаунта и облачной синхронизации.
- Пять оптимизированных стилизованных WebP-портретов созданы по предоставленным референсам. Исходные фотографии в публикуемую игру не включены.
- Нет внешних шрифтов, CDN, сторонних игровых сервисов или аналитики.

## Текущий статус

Happy Home открывается с корневой страницы и во вложенном маршруте `happy-home/`. Подсказка текущего испытания показывается под Canvas и объявляется экранному диктору. Последняя локальная проверка: `npm test` — 70/70; `npm run test:e2e` — legacy E2E, игровой сценарий и проверка 50 паттернов/пяти босс-сцен в имитируемом viewport 320 × 390; `npm run build` — 72 файла в `dist/` (~5,3 МБ). Синтаксис JavaScript и `git diff --check` проходят.

Дополнительная ревизия исправила precache-модули service worker (v3), сохранение при возврате на карту, доступные имена игровых аудиопереключателей и орбитальный/целевой порядок некоторых механик.

**Релиз опубликован:** [Открыть Happy Home](https://miagpt.github.io/game/). PR [#6](https://github.com/miagpt/game/pull/6) объединён в `main`; GitHub Pages deployment завершился успешно (run [46078281835](https://github.com/miagpt/game/actions/runs/46078281835)). CI `Tests` на `main` также прошёл.

Физический iPhone/Safari агентом не проверен; пользовательский плейтест остаётся важной ручной проверкой. Canvas E2E использует browser-free DOM/Canvas mocks и не равен настоящей раскладке или физическому устройству.

## Проверки и сборка

```sh
npm test                  # unit-проверки и целостность сайта
npm install --no-save jsdom@26.1.0 esbuild@0.25.0
npm run test:e2e          # e2e legacy-игры и Happy Home
npm run build             # dist/ по allowlist для GitHub Pages
```

Основные файлы Happy Home:

```text
index.html                  корневая стартовая страница игры
happy-home/index.html       вложенная страница прототипа
happy-home/app.js           Canvas-симуляция, управление, звук, UI и сохранение
happy-home/content.js       герои, 50 раундов, паттерны и длительность
happy-home/style.css        адаптивный интерфейс с приоритетом iPhone
happy-home/portraits/       пять оптимизированных иллюстраций
sw.js                       кэш страниц и WebP-портретов
site.webmanifest            временно сохранённый манифест legacy-сайта

tools/happyhome.test.mjs    проверки глав, сценариев, длительности и локальных ассетов
tools/happyhome-e2e.mjs     тест тача, игрового цикла, паузы, аудио и сохранения
tools/happyhome-boss-e2e.mjs проверка пяти босс-сцен в узком мобильном viewport
tools/site-check.mjs        проверка ссылок, id, локальных ресурсов и структуры сайта
```
