# Поршик 2.0 — кот, который летает

Тёплая браузерная игра-флаппи: дымчатый кот Поршик летит через десять миров к окну, где его ждут.
Статический сайт: HTML, CSS, JavaScript ES-модули и Canvas. Без сборки, серверной части, аналитики,
внешних шрифтов, CDN и сторонних runtime-зависимостей.

**Играть онлайн:** <https://miagpt.github.io/game/>
**Обложки и тексты для Telegram:** <https://miagpt.github.io/game/covers.html>
**Локально:** Node.js 18+, `npm start`, затем <http://localhost:8000>.

## Что это за игра

Поршик — обычный домашний кот, который однажды заметил, что если очень захотеть, лапы начинают
работать как крылья. Десять коротких миров ведут его от крыши у форточки через кухню, чердак,
корзинку с нитками, двор после дождя, дождь на балконе, пекарню и камин — к ночному городу и дому,
где его ждут.

### Управление

| Действие | Клавиатура | Телефон |
| --- | --- | --- |
| Взмах / взлёт | пробел, ↑, W | тап по небу |
| Пауза | Esc или P | кнопка Ⅱ |
| Звук | кнопка ♫ | кнопка ♫ |

### Правила

* **Три жизни** на полёт. Удар отнимает жизнь и даёт короткую неуязвимость — Поршик не падает сразу.
* **Рыбки** — валюта: по рыбке в каждом просвете, дорожка между воротами и лакомства (сосиска,
  булочка, золотая мышка, сливки). Каждые 10 рыбок подряд — премия +2.
* **Три звезды** за мир: долететь, собрать 65% рыбок и не потерять ни одной жизни.
* **Усиления**: пузырь (гасит один удар), магнит (притягивает рыбок 7 с), энергия (5 с мягкой гравитации).
* **Письма и записки**: после каждого мира — записка от Поршика, после десятого — финальное письмо.
* **Бесконечный полёт** открывается после первой победы: миры сменяют друг друга, скорость и
  сложность растут, рекорд сохраняется.

## Проверки

```sh
npm test                  # 60 unit-тестов + проверка целостности сайта
npm start                 # dev-сервер на 0.0.0.0:8000
npm install --no-save jsdom esbuild
npm run test:e2e          # прогон игры в jsdom: 13 с симуляции, ~800k вызовов canvas
npm run build             # dist/ по allowlist для GitHub Pages
```

Что именно проверяется:

* **Содержание** — у каждого мира есть тема, текст, подсказка, допустимый баланс; записки ровно
  по одной на мир, кроме финала; миссии измеримы; облики уникальны.
* **Сохранение** — нормализация любого мусора (включая данные старой версии `pies`/`hearts`),
  запрет отрицательных значений, устойчивость к отсутствию localStorage.
* **Баланс** — бот проходит каждый мир, 30 seed-проверок на трёх жизнях дают ≥12 побед,
  ворота не выходят за границы мира, опасности не ставятся в коридор полёта.
* **Стабильность** — нет NaN, массивы подчищаются, `dt` ограничен, вкладка в фоне не телепортирует.
* **E2E** — меню → полёт → пауза → гардероб → миссии → победа → записка → десятый мир → письмо →
  бесконечный режим → проигрыш → resize → сломанное хранилище.
* **Сайт** — ссылки, якоря, локальные ресурсы, манифест, сервис-воркер, размер ассетов.
* **Версия 2.0 и подарок** — отметка версии на всех страницах, тексты подарка без незаполненных
  переменных, десять обложек с файлами в обоих размерах, совпадение списка обложек в галерее и в
  `tools/covers.mjs`, значки платформ с корректным `viewBox` и без внешних ссылок.

## Приватность и безопасность

Прогресс хранится только в `localStorage` (`porshik.save.v2`) на текущем устройстве. Аккаунтов,
сетевых запросов, аналитики и таблиц лидеров нет. Битое или недоступное хранилище не блокирует игру.
Публикуется только allowlist из `tools/build-site.mjs`: страницы, `assets`, манифест и сервис-воркер.
Исходные архивы, документы и тесты в артефакт не попадают.

## Как менять игру под себя

1. **Текст** — только `assets/js/content.js`: имена, записки, телеграммы, письмо, реплики, миссии.
2. **Баланс** — `assets/js/content.js → LEVELS` (ворот, скорость, просвет) и `assets/js/rules.js`
   (звёзды, награды, бесконечный режим). После правок запустите `npm test`.
3. **Внешний вид** — `assets/js/themes.js` (палитры миров) и `assets/js/render.js` (формы ворот,
   кот, рыбки, опасности).
4. **Новые миры** — добавьте объект в `LEVELS` и тему с тем же ключом в `THEMES`; тесты подскажут,
   если чего-то не хватает.
5. **Обложки** — правьте тексты и палитры в `tools/covers.mjs` (`COVERS`) и запускайте сборку;
   список вариантов в `assets/js/covers-page.js` должен совпадать — это проверяет `npm test`.
